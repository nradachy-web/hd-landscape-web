# URLs

The old WordPress site had five pages. All five keep their exact addresses: `/`, `/services/`, `/about-us/`, `/contact-us/`, `/gallery/`. Nothing needs a forward.

Service pages: `/<service>/`. Town hubs: `/service-areas/<town>/`. Service in a town: `/<service-slug>-<town>-mi/`, only where `MATRIX` in `src/data/cities.ts` says so.
